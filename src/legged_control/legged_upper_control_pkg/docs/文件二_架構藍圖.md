# C1 — x_des 參考軌跡

## 問題

cost (10) 是逐步的，$x^{i,des}_{t+k}$ 需要一條**沿 horizon 的參考序列**，不是單一終點 goal，也不是回授律。

## 核心設計：A* 弧長取樣

Terminal 下 goal → A* 出 global path（waypoint 折線，一次規劃）→ 每控制週期沿路徑**等弧長撒 N 個錨點**：

$$
x^{des}_{t+k}=\begin{bmatrix}p^{des}_{t+k}\\ v^{des}_{t+k}\end{bmatrix},\quad
\begin{cases}
p^{des}_{t+k}=\text{A* 路徑上距當前弧長 } s_k=v_{ref}\cdot kT_s \text{ 處的點}\\
v^{des}_{t+k}=v_{ref}(d_k)\cdot\hat t_k
\end{cases}
$$

- $\hat t_k=\dfrac{p^{des}_{t+k+1}-p^{des}_{t+k}}{\|\cdot\|}$：路徑第 k 點單位切向
- **等弧長**（每點間距 $=v_{ref}T_s$）→ 對應等速前進；等 waypoint 取會速度忽快忽慢

**「撒點」≠ EKF**：撒點是在**已知固定路徑**上量等間距點（純幾何、零不確定性、往前指「想去哪」）；EKF 是從**帶雜訊量測**估計真實狀態（往回看「實際在哪」）。方向相反。

## 速度參考 ≠ 回授律

$v^{des}_{t+k}=v_{ref}\hat t_k$（路徑切向×巡航速率），**不是** $K(p_{des}-p_{now})$。後者是「想停在 $p_{des}$」的比例控制律，會把回授混進參考；中途 waypoint 應「通過」不是「停」，$v_{des}$ 該是巡航切向，只有**終點** waypoint 的 $v_{des}$ 設 0。

## 減速：純阻尼放在參考層（不放 limiter）

$$
v_{ref}(d)=v_{cruise}\cdot\min\!\Big(1,\ \frac{d}{d_{brake}}\Big)
$$

- $d$：該錨點**沿 A* 路徑到終點的剩餘弧長**（$d_k=L_{total}-s_k$），**不是直線距離**（繞牆時直線會誤判提早停）
- $d\ge d_{brake}$：全速 $v_{cruise}$；$d<d_{brake}$：線性收到 0；$d=0$：停
- `min` 作用：遠處封頂在 $v_{cruise}$（防 $d/d_{brake}>1$ 放大速度）
- **放參考層（step 3）不放 limiter（step 7）**：planner 自己知道要慢下來 → 解出的軌跡本身平滑煞停，不需出口拔河（避免 case 3 near-wall 橫向振盪的病根）

> **可選強化**：$v_{ref}=\sqrt{2a_{max}d}$（等減速度物理煞停），末端減速貼合加速度上限；線性版通常夠用，末端過衝再換。

## 轉角平滑（Bézier，先不加）

A* 折線轉角不可微 → 切向階躍 → yaw 目標跳。三次 Bézier（4 控制點 $B(u)=(1{-}u)^3P_0+3(1{-}u)^2uP_1+3(1{-}u)u^2P_2+u^3P_3$）可把尖角換成二階可微曲線 → 切向連續。**但先不加**：A8 yaw 旁路有 EMA+低速凍結，先跑 Gazebo 看轉角行為，抖再加 Bézier（不預先加複雜度）。

# C2 — 編隊成本進 cost

## 數學（ZJU FAST-Lab 正規化 Laplacian，非剛性 δ 版）

repo `LaplacianFormation` 實作（註解 893–896）：

$$
w_{ij}=\|p_i-p_j\|^2\ (i\ne j),\quad
D_{ii}=\sum_{k}w_{ik},\quad
L=D-W,\quad
\hat L=D^{-1/2}LD^{-1/2}
$$
$$
\hat L_{ij}=-\frac{w_{ij}}{\sqrt{D_{ii}D_{jj}}}\ (i\ne j),\ \hat L_{ii}=1,\qquad
\boxed{f_{form}=\|\hat L-\hat L_{des}\|_F^2}
$$

$\hat L_{des}$：理想隊形（V/line）預算的正規化 Laplacian（`set_formation` 註冊）。

**物理**：$\hat L$ 是隊形**形狀指紋**；正規化除掉尺度 → 只認形狀、不認絕對位置和大小 → 隊形可自由平移/縮放/旋轉避障，只要形狀相似就不罰。**這是「動態鬆緊」哲學的數學根基**。

## 耦合結構：all-to-all（不是 pairwise）

正規化分母 $\sqrt{D_{ii}D_{jj}}$ 含 $D_{ii}=\sum_k\|p_i-p_k\|^2$ → 牽進**第三隻狗**。故 $\partial f/\partial p_i$ 依賴**全部**狗位置（repo `compute` 第 984 行對所有 j 求和）。$f$ **不能**拆成 $f^{12}+f^{13}+f^{23}$ → **裝不進 edge**（edge 只吃兩端）。

## 解法：線性化 → 塌成 node 線性項

在 ADMM 迴圈**外**、參考軌跡 $\bar p$ 上算凍結梯度 $g_{i,k}=\nabla_p f|_{\bar p_k}$（常數向量）。線性化後 all-to-all 耦合被凍進常數 → 狗 $i$ 的編隊項只剩 $g_{i,k}^\top p^i_k$（線性）→ **進 node**。

**結論**：**編隊在 node（線性化塌成常數梯度）、避撞在 edge（pairwise CBF）**，乾淨分離。

## 放哪層 / 哪步

- **權重** $w_{form}(\rho_{obs})$ 隨障礙密度：開闊大、障礙區小 → 放 **cost 權重層每週期重算**（不放 limiter；want 的強度調在 cost）
- **編隊項** 放 **stage cost**（每步 $k=0..N-1$ 加），**不放 terminal**（隊形一路維持，非終點才對齊；且相對形狀無「收斂到定點」概念）

## 雞生蛋的破解

沿 horizon 每步算 $\nabla f$ 需要「未來每步狗位置」= ADMM 要解的東西。破解：用**上週期解平移一格**當操作點（已含未來每步預測位置）→ 迴圈外算一次 $\{g_{i,k}\}_{k=0}^N$ 凍結 → 20 輪共用。與論文對 CBF 的 successive linearization **同時機、同操作點、同凍結**。

3 狗 × N 步 = $3N$ 個梯度，迴圈外每週期算一次。

# C3 — Xiong 兩階離散 HOCBF

## 為什麼要兩階（relative degree 2）

輸入是加速度 $a$，但 $h=\|p_i-p_j\|^2-d^2$ 只跟位置有關。位置離加速度隔兩層積分（$a\to v\to p$）→ 對 $h$ 差分**一次**只到速度、**兩次**才到加速度 → 兩階。

## 遞迴定義（從一階 $\Delta h\ge-\alpha h$ 出發）

一階：$h_{k+1}-h_k\ge-\alpha h_k$。套兩層（定義新 barrier 再套一次）：
$$
\psi_{1,k}=\Delta h_k+\alpha_1 h_k=h_{k+1}-(1-\alpha_1)h_k
$$
$$
\psi_{2,k}=\Delta\psi_{1,k}+\alpha_2\psi_{1,k}\ge0
$$

## 完全展開（三個時間步）

代入化簡（$\alpha_i$ 即 repo 的 $\gamma_i$）：
$$
\boxed{h_{k+2}-(2-\gamma_1-\gamma_2)\,h_{k+1}+(1-\gamma_1-\gamma_2+\gamma_1\gamma_2)\,h_k\ge0}
$$

**$\gamma_1\gamma_2$ 為正號**（來自 $(1-\gamma_1)(1-\gamma_2)$；與連續版 $(\gamma_1{-}1)(\gamma_2{-}1)$ 一致）。負號是筆誤。
校驗（$\gamma=0.3$）：$h_k$ 係數 $=1-0.3-0.3+0.09=0.49$（正號）vs 錯誤負號 0.31，差 37%。

**物理**：不只看現在安不安全，看未來兩步 → 提前預判、提前煞（一階單步太 myopic 是早期凍結根因）。

## 動力學代入：$a_k$ 只從 $h_{k+2}$ 進來

double integrator（C3 推導用簡化前向歐拉）：
$$
p_{k+2}=p_k+2v_kT_s+a_kT_s^2
$$
→ $a_k$ **只影響 $p_{k+2}$**（$h_{k+1}$ 只含 $v_k$、$h_k$ 是常數）。故唯一需線性化的是 $h_{k+2}$。

> **實作對齊**：組矩陣用精確 $B_d$（含 $\frac12aT_s^2$）時，$p_{k+2}$ 對 $a_k$ 係數變 $\frac32T_s^2$（$B_d$ 一步 + $A_d$ 傳遞一步）。邏輯不變，係數重算。

## 線性化（泰勒一階 = 切平面近似）

$h_{k+2}=\|e_{k+2}\|^2-d^2$，$e_{k+2}=p^i_{k+2}-p^j_{k+2}$。在參考點 $\bar e_{k+2}$ 一階展開（$\nabla\|e\|^2=2e$）：
$$
h_{k+2}\approx \underbrace{c_{k+2}}_{\text{常數}}+2T_s^2\bar e_{k+2}^\top a^i_k-2T_s^2\bar e_{k+2}^\top a^j_k
$$

- 丟掉的二次項是 $T_s^4\|a^i_k-a^j_k\|^2$（$T_s^4$ 極小可忽略）
- $2\bar e_{k+2}$ = 曲面在參考點的梯度，物理指兩狗連線方向（最敏感避撞方向）
- 對 $a^i,a^j$ 係數大小同、符號反 → 一推一拉對稱 → 對應 edge QP 的 col_a, col_b
- 保留 $a^i,a^j$ 兩變數 → **耦合 → 進 edge**（與 C2 塌成 node 相反）
- 參考點 = 上週期解平移一格（近才準）；迴圈外每週期線性化一次（迭代間狀態幾乎不動 + 線性化貴）

## 最終 edge 約束

代回二階約束，分離 $a$ 與常數：
$$
\boxed{-2T_s^2\bar e_{k+2}^\top a^i_k+2T_s^2\bar e_{k+2}^\top a^j_k\le b_k}
$$
$$
b_k=c_{k+2}-(2-\gamma_1-\gamma_2)h_{k+1}+(1-\gamma_1-\gamma_2+\gamma_1\gamma_2)h_k\ \text{（參考點凍結常數）}
$$

> ⚠️ **係數已作廢，勿照抄。** 上式的 $2T_s^2$ 是前向歐拉簡化版。實作一律用精確 $B_d$，
> CBF 約束係數為 **$3T_s^2$**（見 `spec_updates_v2.md` 細節 1，由 `test_constants.py` 守門）。
> 上式保留僅為推導脈絡；寫 code 時 col_a $=-3T_s^2\bar e_{k+2}$、col_b $=+3T_s^2\bar e_{k+2}$。
加 slack：$\le b_k+s^{ij}_k$。標準線性不等式 $A_{cbf}a\le b_{cbf}+s$，QP 直接吃。這是**二階**（比論文一階強）的差異化貢獻。

# C4 — QP 矩陣組裝

每週期 ADMM 迴圈外先線性化（凍結 CBF 係數、編隊梯度、$\bar\xi$），再組 5 塊。

## C4.1 node Hessian $H$（$6N\times6N$）

```
H = blkdiag(Q,...,Q,P,  R,...,R) + ρ·|N(i)|·I_{6N}
           └N-1個Q┘└P┘ └N個R┘
```
- 狀態塊：`H[4(k-1):4k, 4(k-1):4k] += Q`（k=1..N-1）；`H[4(N-1):4N,4(N-1):4N] += P`
- 加速度塊：`H[4N+2k:4N+2k+2, 同] += R`（k=0..N-1）
- 共識罰：`H += rho*len(N_i)*I(6N)`（整條對角）

**讀對角格 SOP**：定位 index → 加專屬罰（狀態 Q / 加速度 R）→ 加共識罰 $\rho|\mathcal N(i)|$。
例：$H[40,40]=r+40$（index 40=$a_{x,0}$）；$H[0,0]=Q_{11}+40=90$。
塊對角極稀疏（multiple-shooting 紅利），共識罰增正定性。

## C4.2 node 線性項 $f$（$6N$）

$$
f=\underbrace{-Q\,x^{des}_k}_{\text{C1（每步狀態）}}+\underbrace{w_{form}g_{i,k}}_{\text{C2（每步僅位置兩格）}}+\underbrace{-\rho|\mathcal N(i)|\bar c^i}_{\text{共識（整個}\xi\text{）}}
$$
- C1：`f[4(k-1):4k] += -Q @ x_des[k]`；terminal `f[4(N-1):4N] += -P @ x_des[N]`
- C2：`f[4(k-1):4(k-1)+2] += w_form*g[i,k]`（**只位置 index，速度不加**，梯度速度分量為 0）
- 共識：`f += -rho*len(N_i)*c_bar`，$\bar c^i=\frac1{|\mathcal N(i)|}\sum_j(z^{ij,i}-\lambda^{ij,i})$

## C4.3 node 動態等式 $A_{eq}\xi=b_{eq}$（$4N\times6N$）

$$
x_{k+1}=A_dx_k+B_da_k,\quad
A_d=\begin{bmatrix}I_2&T_sI_2\\0&I_2\end{bmatrix},\
B_d=\begin{bmatrix}\frac12T_s^2I_2\\T_sI_2\end{bmatrix}
$$
- k=0（初始，$x_0=x(t)$ 實測）：`A_eq[0:4, a0]=-B_d`；`A_eq[0:4, x1]=I4`；`b_eq[0:4]=A_d@x_now`
- k≥1：`A_eq[4k:4k+4, x_k]=-A_d`；`[.., x_{k+1}]=I4`；`[.., a_k]=-B_d`；`b_eq=0`

稀疏帶狀（每條只碰 $x_k,x_{k+1},a_k$）。

## C4.4 node 局部不等式 $A_{ineq}\xi\le b_{ineq}$

- **障礙/rect/牆 CBF**（單狗，論文 (7)）：二階展開→代動力學→線性化，得 $a^i_k$ 線性不等式（只含 $a^i$）。牆 $h=n_w^\top(p-p_w)-d$ 仿射免線性化。k=0 硬約束、k≥1 soft（w_pred）。
- **bounds**：$|v_{x,k}|\le0.55,|v_{y,k}|\le0.35,|a_{x,k}|\le1.0,|a_{y,k}|\le1.0$（尊重底層，各兩條 ±）。

## C4.5 edge QP（每邊一個，共 3）

決策 $(z^{ij,i},z^{ij,j},s^{ij})$，維度 $\approx12N+n_s$（$N=10$→$120+n_s$）。

**cost**：
$$
\varphi(s)+\frac\rho2\|z^{ij,i}-\xi^i-\lambda^{ij,i}\|^2+\frac\rho2\|z^{ij,j}-\xi^j-\lambda^{ij,j}\|^2
$$
- $\varphi=\lambda_{slk}s^2$（Hessian s 塊 $+2\lambda_{slk}$）；兩 proximal（Hessian $z$ 塊各 $+\rho I_{6N}$，線性 $-\rho(\xi+\lambda)$）

**約束（C3 pairwise CBF，作用在分身 $z$）**：
$$
-2T_s^2\bar e_{k+2}^\top a^i_k(z)+2T_s^2\bar e_{k+2}^\top a^j_k(z)\le b_k+s^{ij}_k
$$
> ⚠️ 同上：$2T_s^2$ 作廢，實作用 **$3T_s^2$**（`spec_updates_v2.md` 細節 1）。
- col_a$=-3T_s^2\bar e_{k+2}$；col_b$=+3T_s^2\bar e_{k+2}$（**精確 $B_d$，係數 $3T_s^2$；`spec_updates_v2.md` 細節 1 為準，`test_constants.py` 守門**。舊的 $2T_s^2$ 前向歐拉版作廢）
- $b_k$ 見 C3；slack 必要（slack_enabled=True）

# C5 — ADMM 迴圈骨架 + 殘差量測

## C5.1 四模組

```
RTILinearizer   迴圈外每週期一次: 上週期解平移→ξ̄; 凍結 CBF係數/編隊梯度/A_d,B_d/b_k
NodeSubproblem  每狗一 QP: 組H,f,A_eq,A_ineq(C4.1-4.4)→cvxpy→ξ^i
EdgeSubproblem  每邊一 QP: 組edge cost/約束(C4.5)→cvxpy→z,s
ADMMCoordinator 主迴圈: init z0,λ0 → node→edge→dual → 殘差量測
```

## C5.2 主迴圈偽碼

```python
# 每控制週期 10 Hz:
xi_bar = shift_prev_solution(prev_xi)       # 平移; 第一週期用無耦合MPC
frozen = RTILinearizer(xi_bar, state_now)   # 迴圈外線性化一次
z, lam = warm_start(prev_z, prev_lam)        # 平移; 第一週期 z0=無耦合解, lam0=0
for p in range(P_max):                        # 15~20
    for i in dogs:                            # Node 並行3
        xi[i] = NodeSubproblem(i, frozen, z, lam).solve()
    for (i,j) in edges:                       # Edge 並行3
        z[i,j,i], z[i,j,j], s[i,j] = EdgeSubproblem(i,j, xi, lam, frozen).solve()
    for (i,j) in edges:                       # Dual (scaled, 無ρ係數)
        lam[i,j,i] += xi[i]-z[i,j,i]; lam[i,j,j] += xi[j]-z[i,j,j]
    r_prim, r_dual, h2_viol = measure_residuals(xi, z, z_prev)  # C5.4
    publish_residuals(r_prim, r_dual, h2_viol)
    if converged(r_prim, r_dual): break
    z_prev = deepcopy(z)
prev_xi, prev_z, prev_lam = xi, z, lam
send_to_ocs2(xi)                              # Route 乙; C6
```

## C5.3 資料結構（z 按 edge 存）

```python
# ✅ z[edge][endpoint]: 一狗屬多邊有多份分身
z = {(1,2):{1:vec6N,2:vec6N}, (1,3):{1:vec6N,3:vec6N}, (2,3):{2:vec6N,3:vec6N}}
# 狗1有 z[(1,2)][1], z[(1,3)][1] 兩份 → 對應|N(1)|=2
# ❌ z[node] 會混淆不同邊的分身, node update 的 Σ_{j∈N(i)} 錯
```

## C5.4 殘差量測（取代兜底，A10）

| 量 | 公式 | topic |
|---|---|---|
| primal residual | $\|\xi_p-z_p\|$ | /admm/r_prim |
| dual residual | $\rho\|z_p-z_{p-1}\|$ | /admm/r_dual |
| **h2 違反量** | $\max(-h_2^{ij}(\xi^i,\xi^j))^+$ | /admm/h2_viol |

**h2_viol 最關鍵**：用收斂後**真身** $\xi$ 代回 $h_2\ge0$ 量負值，是要不要兜底的真正依據，量化上報（誠實框架：slack>0 該步無嚴格保證）。**不做** watchdog/emergency brake（slack 開著不 infeasible，舊 brake 是 dead code）。

## C5.5 殘差大處理優先序
1. warm-start 檢查 → 2. 調 ρ（先確認 wall-clock<100ms）→ 3. 加輪數（先看曲線形狀）

## C5.6 初始化（A9）
第一週期各 agent 無耦合 MPC（局部動態+障礙，不含 inter-agent）填 $z_0$；之後 warm-start；$\lambda_0=0$；收斂與初值無關。

## 附錄 B：核心設計決定速查

| 決定 | 內容 | 原因 |
|---|---|---|
| x_des = A* 弧長取樣 | 沿路徑撒 N 錨點，非單點 | cost 逐步需序列 |
| v_des = $v_{ref}\hat t$ | 切向×速率，非 $K(p_{des}-p_{now})$ | 參考≠回授律 |
| 減速放參考層 | $v_{ref}(d)$ 隨剩餘弧長收 | 避免 limiter 拔河 |
| 編隊進 node | Laplacian 線性化塌成常數梯度 | all-to-all 裝不進 edge |
| 避撞進 edge | pairwise CBF 保留雙變數 | 乾淨 pairwise |
| 二階 CBF | $h_2\ge0$，$\gamma_1\gamma_2$ **正號** | 比論文一階強（差異化貢獻） |
| 線性化迴圈外一次 | 迭代間狀態不動+線性化貴 | successive linearization |
| Route 乙送整條 | 只送狀態序列，加速度丟棄 | toLeggedControl 回零 |
| 不做兜底 | 改埋 h2_viol 量測 | slack 開著不 infeasible |
