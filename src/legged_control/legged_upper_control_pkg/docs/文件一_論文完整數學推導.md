## Part 1：系統建模與安全集 (1)–(3)

### 1.1 多機器人系統與互動圖

考慮 $n_\mathcal{V}$ 台四足機器人，索引集合 $\mathcal{V}:=\{1,\dots,n_\mathcal{V}\}$。系統用一張**無向互動圖** $\mathcal{G}(\mathcal{V},\mathcal{E})$ 描述耦合關係，邊集

$$\mathcal{E}:=\{\{i,j\}\mid i,j\in\mathcal{V},\ i\ne j\}$$

**物理意義**：節點 = 機器人，邊 = 「這兩台需要互相避讓」的關係。無向是因為碰撞對稱（「$i$ 避開 $j$」與「$j$ 避開 $i$」是同一件事）。

**為什麼這樣設計**：整篇 node–edge splitting 完全建立在這張圖上 —— node update 對應節點、edge update 對應邊，圖結構決定通訊拓撲。論文採用 complete graph（每台都相鄰）。

### 1.2 單機動態 (1)

每台 agent $i$ 的離散時間非線性動態：

$$x^i(t+1)=f^i\big(x^i(t),u^i(t)\big) \tag{1}$$

其中 $x^i\in\mathcal{X}\subset\mathbb{R}^{n_x}$ 是局部狀態，$u^i\in\mathcal{U}\subset\mathbb{R}^{n_u}$ 是局部輸入，$f^i:\mathcal{X}\times\mathcal{U}\to\mathcal{X}$ 是動態。另定義連續映射 $g:\mathcal{X}\to\mathbb{R}^2$，使 $g(x^i)$ 給出 agent $i$ 的質心 (CoM) 平面位置。

**物理意義**：$g$ 是「從完整狀態抽出 xy 位置」的投影。碰撞只跟位置有關，與速度、朝向無關，所以 $g$ 把碰撞判斷從整個狀態空間縮到平面位置。

**為什麼這樣設計**：論文刻意讓框架**與具體模型解耦**。(1) 寫成抽象 $f^i$、位置寫成抽象 $g$，意思是「ADMM 框架不管底層用什麼模型」。到 (22) 才具體化成 kinematic car。**這是文件二能成立的根本** —— 換 double integrator 就是換掉 $f^i$ 與 $g$，整個 ADMM 結構不變。

### 1.3 障礙物與安全集 (3)

靜態障礙物集合 $\mathcal{O}:=\{1,\dots,n_\mathcal{O}\}$，$o^\ell\in\mathbb{R}^2$ 是障礙 $\ell$ 的中心。定義兩個安全集：

**inter-agent 安全集**（機器人之間不撞）：

$$\mathcal{S}_\mathcal{V}:=\Big\{x\in\mathbb{R}^{n_\mathcal{V}n_x}\ \Big|\ \|g(x^i)-g(x^j)\|\ge d_{th},\ \forall\{i,j\}\in\mathcal{E}\Big\}$$

**agent-obstacle 安全集**（機器人不撞障礙）：

$$\mathcal{S}_\mathcal{O}:=\Big\{x\ \Big|\ \|g(x^i)-o^\ell\|\ge d_{th},\ \forall i\in\mathcal{V},\forall\ell\in\mathcal{O}\Big\}$$

**全局安全集**：

$$\mathcal{S}:=\mathcal{S}_\mathcal{V}\cap\mathcal{S}_\mathcal{O} \tag{3}$$

其中 $\|\cdot\|$ 是歐式範數，$d_{th}>0$ 是安全門檻（論文 $0.5$ m）。

**物理意義**：$\mathcal{S}_\mathcal{V}$ 說任兩台相鄰機器人距離 $\ge d_{th}$；$\mathcal{S}_\mathcal{O}$ 說每台離每個障礙 $\ge d_{th}$。$\mathcal{S}$ 是「全部安全條件同時滿足」的狀態集合。

**為什麼分成兩個集合（關鍵伏筆）**：這個拆分是 node–edge splitting 的伏筆：

- $\mathcal{S}_\mathcal{O}$ 的條件 $\|g(x^i)-o^\ell\|\ge d_{th}$ **只含單一 agent $i$** → 局部 → 之後進 node 的 $\Xi^i$
- $\mathcal{S}_\mathcal{V}$ 的條件 $\|g(x^i)-g(x^j)\|\ge d_{th}$ **同時含 $i,j$** → 耦合 → 之後進 edge

論文從定義安全集就把「局部 vs 耦合」結構埋好了，這不是巧合，是為了讓 ADMM 分解有對象。

## Part 2：離散時間 CBF (4)–(8)

### 2.1 動機：為什麼需要 CBF

安全集 $\mathcal{S}$ 定義好了，但「待在 $\mathcal{S}$ 裡」不能直接給 MPC 用。問題：你只能在當下選 $u(t)$，怎麼知道它會不會害你**未來**離開 $\mathcal{S}$？只看下一步 $x(t+1)\in\mathcal{S}$ 不夠 —— 可能下一步還在，但已衝太快、第三步必出界且來不及煞。

你需要的是「**一旦在安全集內，就永遠出不去**」的性質，叫 **forward invariance（前向不變性）**。CBF 正是保證它的工具。

### 2.2 離散 CBF 定義 (4)

**Definition 1（Discrete-Time CBF [35]）**：函數 $h^i$ 是 (1) 的 CBF，若存在 class-$\mathcal{K}$ 函數 $\alpha$ 滿足 $\alpha(s)<s\ (\forall s>0)$，使得

$$\Delta h^i\big(x^i(t),u^i(t)\big)\ge-\alpha\big(h^i(x^i(t))\big),\quad\forall x^i(t)\in\mathcal{X} \tag{4}$$

其中 $\Delta h^i(x^i(t),u^i(t)):=h^i(x^i(t+1))-h^i(x^i(t))$。

**拆解這個式子。** 把 $\Delta h=h(t+1)-h(t)$ 代回並移項：

$$h^i(x^i(t+1))\ge h^i(x^i(t))-\alpha\big(h^i(x^i(t))\big)$$

**物理意義（核心直覺）**：$h$ 是「安全餘裕」（$h\ge0$ 安全，越大越安全）。式子說：下一刻的餘裕，不准比「當前餘裕扣掉 $\alpha(h)$」還低。因 $\alpha(s)<s$，故 $h-\alpha(h)>0$（只要 $h>0$）—— **允許下降，但下降後仍須為正**。

$\alpha$ 控制「允許多快接近邊界」，是一個自適應煞車：

- $h$ 大（離邊界遠）：$\alpha(h)$ 大，允許 $h$ 大幅下降 → 可全速衝
- $h\to0$（逼近邊界）：$\alpha(h)\to0$，故 $h(t+1)\ge h(t)-\alpha(h(t))\approx h(t)>0$ → 強迫 $h$ 在邊界附近幾乎不降 → 煞住

**class-$\mathcal{K}$**：$\alpha:[0,\infty)\to[0,\infty)$ 連續、嚴格遞增、$\alpha(0)=0$。論文取線性 $\alpha(s)=0.3s$，讓 CBF 條件變線性不等式，方便進 QP。

### 2.3 Forward invariance 定理

**Theorem 1**：若 $h^i$ 是連續 CBF，任何滿足 (4) 的 $u^i(t)\in\mathcal{U}$ 使安全集 $\mathcal{S}:=\{x^i:h^i(x^i)\ge0\}$ 對 agent $i$ 前向不變。

**證明直覺（歸納法）**：設 $h(t)\ge0$。由 (4)，$h(t+1)\ge h(t)-\alpha(h(t))$。因 $\alpha(h(t))<h(t)$（當 $h(t)>0$），右邊 $>0$，故 $h(t+1)\ge0$。邊界情形 $h(t)=0$ 時 $\alpha(0)=0$ 得 $h(t+1)\ge0$。歸納成立 → 一旦進安全集就永遠不出。

**CBF 的核心價值**：把「未來永遠安全」這個無窮時間條件，壓縮成「每步滿足一個只看當下與下一步的不等式 (4)」。MPC 只要在每個預測步加上 (4)，自動保證整條軌跡的 forward invariance。

### 2.4 兩類具體 CBF (5)(6)

**agent-obstacle**（對應 $\mathcal{S}_\mathcal{O}$）：

$$h^{i,\ell}(x^i):=\|g(x^i)-o^\ell\|-d_{th} \tag{5}$$

**inter-agent**（對應 $\mathcal{S}_\mathcal{V}$）：

$$h^{i,j}(x^i,x^j):=\|g(x^i)-g(x^j)\|-d_{th} \tag{6}$$

**物理意義**：$h^{i,\ell}=$「agent $i$ 到障礙 $\ell$ 的距離」減「門檻」；$h\ge0\iff$ 距離 $\ge d_{th}\iff$ 安全。$h^{i,j}$ 是兩台機器人版本。注意 $h^{i,\ell}$ **只含 $x^i$**，$h^{i,j}$ **同時含 $x^i,x^j$** —— 延續局部 vs 耦合。

### 2.5 兩個 CBF 條件 (7)(8) — 耦合的根源

把 (5)(6) 代進 (4)：

**obstacle 條件（局部）**：

$$\Delta h^{i,\ell}\big(x^i(t),u^i(t)\big)\ge-\alpha\big(h^{i,\ell}(x^i(t))\big) \tag{7}$$

**inter-agent 條件（耦合）**：

$$\Delta h^{i,j}\big(x^i(t),x^j(t),u^i(t),u^j(t)\big)\ge-\alpha\big(h^{i,j}(x^i(t),x^j(t))\big) \tag{8}$$

其中 $\Delta h^{i,j}:=h^{i,j}(x^i(t+1),x^j(t+1))-h^{i,j}(x^i(t),x^j(t))$。

**整篇論文的問題核心，要看清楚。** 對比 (7) 和 (8)：

- **(7)** 的 $\Delta h^{i,\ell}$ 只依賴 $x^i(t),u^i(t)$（因 $h^{i,\ell}(x^i(t+1))=h^{i,\ell}(f^i(x^i,u^i))$ 只用 agent $i$ 自己）→ **完全局部，可放進 agent $i$ 自己的 MPC**。
- **(8)** 的 $\Delta h^{i,j}$ 同時依賴 $x^i(t+1)$ 與 $x^j(t+1)$，而兩者各由 $f^i,f^j$ 決定 → **同時耦合 $i,j$ 兩台的狀態與輸入**。

**為什麼這是大麻煩**：agent $i$ 要驗證 (8)「我下一步安不安全」，需要知道 agent $j$ 下一步怎麼動（$u^j$）。但分散式下 $u^j$ 是 $j$ 自己在解的、$i$ 拿不到。**(8) 這條約束讓你沒辦法把問題拆成各管各的局部 MPC** —— 這正是論文摘要說的 "explicit inter-agent coupling, which prevents direct decomposition"，也是整個 ADMM node–edge splitting 要解決的標的。

## Part 3：中心化 MPC 與問題重構 (9)–(12)

### 3.1 預測軌跡記號

在時刻 $t$ 對未來 $N$ 步的預測：

$$x^i(\cdot):=\mathrm{col}\{x^i_{t+1|t},\dots,x^i_{t+N|t}\}\in\mathbb{R}^{Nn_x}$$
$$u^i(\cdot):=\mathrm{col}\{u^i_{t|t},\dots,u^i_{t+N-1|t}\}\in\mathbb{R}^{Nn_u}$$

$x^i_{t+k|t}$ = 「在 $t$ 預測的、未來 $t+k$ 的狀態」。初始條件鎖在當前真實狀態：$x^i_{t|t}=x^i(t)$。

把一台 agent 的整條狀態-輸入軌跡打包成單一向量：

$$\xi^i:=\mathrm{col}\big(x^i(\cdot),u^i(\cdot)\big)\in\mathbb{R}^{N(n_x+n_u)}$$

**物理意義**：$\xi^i$ 是「agent $i$ 對未來 $N$ 步的完整計畫」—— 每步打算在哪（$x$）、每步打算怎麼動（$u$），串成一根長向量。這就是後文的「真身軌跡」。

**multiple-shooting 體現**：狀態 $x(\cdot)$ 和輸入 $u(\cdot)$ **都**是決策變數（都在 $\xi^i$ 裡），論文沒有把狀態 rollout 消掉，而是讓它們也當變數，用動態 (1) 當等式約束綁起來。kinematic car（$n_x=3,n_u=2$）時 $\xi^i\in\mathbb{R}^{5N}$（$N=50$ 為 250 維）。

### 3.2 中心化 CBF-MPC 問題 (9)

$$\min_{(\xi^1,\dots,\xi^{n_\mathcal{V}})}\ \sum_{i\in\mathcal{V}}J^i(\xi^i)$$

$$\text{s.t.}\quad\begin{cases}
x^i_{t+k+1|t}=f^i(x^i_{t+k|t},u^i_{t+k|t}), & i\in\mathcal{V}\quad\text{(動態)}\\[2pt]
\Delta h^{i,\ell}_{t+k|t}\ge-\alpha(h^{i,\ell}_{t+k|t}), & i\in\mathcal{V},\ell\in\mathcal{O}\quad\text{(obstacle CBF)}\\[2pt]
\Delta h^{i,j}_{t+k|t}\ge-\alpha(h^{i,j}_{t+k|t}), & \{i,j\}\in\mathcal{E}\quad\text{(inter-agent CBF)}\\[2pt]
x^i_{t|t}=x^i(t), & i\in\mathcal{V}\quad\text{(初始條件)}
\end{cases} \tag{9}$$

（對 $k=0,\dots,N-1$ 沿整個 horizon 成立。）

**物理意義**：「上帝視角」問題 —— 一個中央大腦同時掌握所有機器人，一次解出全隊最佳安全計畫。

**為什麼叫中心化、為什麼是問題**：目標 $\sum_i J^i$ 雖可分，但 inter-agent CBF 把不同 agent 的 $\xi^i,\xi^j$ 綁在同一問題裡。決策變數是**所有 agent 軌跡的堆疊**，必須中央節點一次解完。隨 agent 數成長維度暴增、需全局通訊 —— 這是論文要分散化的對象。

### 3.3 Cost 結構 (10)

$$J^i(\xi^i):=J^i_{\text{terminal}}\big(x^i_{t+N|t}-x^{i,\text{des}}_{t+N|t}\big)+\sum_{k=0}^{N-1}J^i_{\text{stage}}\big(x^i_{t+k|t}-x^{i,\text{des}}_{t+k|t},\ u^i_{t+k|t}\big) \tag{10}$$

二次形式（$\|x\|^2_M:=x^\top Mx$）：

$$J^i_{\text{terminal}}(x^i)=\|x^i\|^2_{P^i},\qquad J^i_{\text{stage}}(x^i,u^i)=\|x^i\|^2_{Q^i}+\|u^i\|^2_{R^i}$$

$(P^i,Q^i,R^i)$ 正定。

**物理意義**：罰兩件事 ——「偏離參考軌跡 $x^{i,\text{des}}$ 多遠」（$Q^i,P^i$）與「用多大控制力」（$R^i$）。terminal 項 $P^i$ 單獨罰末端偏離，權重通常大（論文 $P^i=10Q^i$），逼近末端收斂。

**為什麼正定（收斂伏筆）**：正定 → cost 嚴格凸 → 子問題有唯一最小值、QP 可解、ADMM 收斂有保障。**cost 的凸性是乾淨的；真正的非凸性全來自 CBF 約束**（$h$ 含 $\|\cdot\|$，約束集非凸）。記住這個分工，Part 6 會回來。

### 3.4 局部可行集 $\Xi^i$ 與第一次重構 (11)(12)

觀察 (9) 四種約束：動態、obstacle CBF、inter-agent CBF、初始條件 —— 其中**前兩項是純局部的**（只含 $x^i,u^i$），只有 inter-agent CBF 耦合。把所有局部約束打包：

$$\Xi^i:=\big\{\xi^i\ \big|\ \text{局部動態 (1) 與局部 CBF (7) 都滿足}\big\} \tag{11}$$

**物理意義**：$\Xi^i$ 是「agent $i$ 自己一台就能檢查的所有可行軌跡」—— 動態合法、不撞障礙、從當前狀態出發，完全不需要知道別人。

於是 (9) 改寫成乾淨抽象形式：

$$\min_{\{\xi^i\}}\ \sum_{i\in\mathcal{V}}J^i(\xi^i)$$
$$\text{s.t.}\quad\begin{cases}
\xi^i\in\Xi^i, & i\in\mathcal{V}\quad\text{(局部可行)}\\[2pt]
\psi^{ij}(\xi^i,\xi^j)\le0, & \{i,j\}\in\mathcal{E}\quad\text{(耦合不等式)}
\end{cases} \tag{12}$$

其中 $\psi^{ij}(\xi^i,\xi^j)\le0$ 把整條 horizon 的 inter-agent CBF (8) 收成緊湊符號。

**整篇的轉折點**：(12) 把 (9) 的四種約束乾淨地分成兩類 —— $\xi^i\in\Xi^i$（節點局部）與 $\psi^{ij}\le0$（邊耦合）。**所有耦合被孤立到 $\psi^{ij}$ 這唯一一項**。可分目標 + 局部約束 + 少數耦合約束，正是 ADMM 喜歡的形狀。後續 (13)–(17) 全是在處理這唯一的耦合項。

## Part 4：從 (12) 到 ADMM 三步 (13)–(21)

整條鏈，每一步只解決前一步留下的一個障礙：

$$\underbrace{\psi^{ij}\le0\ \text{是不等式}}_{\text{障礙1}}\xrightarrow{\text{(13) slack}}\underbrace{\psi^{ij}+s^{ij}=0\ \text{是等式}}_{\text{障礙2}}\xrightarrow{\text{(14)-(17) 分身}}\underbrace{\text{耦合移到 edge}}_{}\xrightarrow{\text{(19)-(21)}}\text{三步交替}$$

### 4.1 slack 把不等式變等式 (13)

ADMM 標準形式要求耦合出現在**等式**約束（Boyd Ch.3）。引入 slack $s^{ij}\ge0$ 與凸二次罰 $\varphi(s^{ij})$（論文 $\varphi(s)=5s^2$）：

$$\min_{\{\xi^i\},\{s^{ij}\}}\ \sum_{i}J^i(\xi^i)+\sum_{\{i,j\}}\varphi(s^{ij})$$
$$\text{s.t.}\quad\xi^i\in\Xi^i,\quad\psi^{ij}+s^{ij}=0,\quad s^{ij}\ge0 \tag{13}$$

**為什麼**：純為塞進 ADMM 標準模具。$s^{ij}$ 吸收「$\psi^{ij}$ 離 0 還差多少」，$\varphi$ 確保整體目標對 $\{s^{ij}\}$ 正定。

### 4.2 node–edge splitting — 把耦合搬到 edge (14)–(18)

**問題**：$\psi^{ij}+s^{ij}=0$ 仍直接耦合 $\xi^i,\xi^j$。不處理的話 node $i$ 子問題就得知道 $\xi^j$ → 沒解耦。

**解法 — 造分身**：對每條邊 $\{i,j\}$ 建立 $\xi^i,\xi^j$ 的邊端副本

$$z^{ij,i}\approx\xi^i,\quad z^{ij,j}\approx\xi^j,\quad s^{ij}\ge0 \tag{14}$$

加上 **consensus 約束**（分身=真身）：

$$z^{ij,i}=\xi^i,\quad z^{ij,j}=\xi^j,\quad\forall\{i,j\}\in\mathcal{E} \tag{15}$$

把耦合約束改寫成**只作用在分身上**：

$$\psi^{ij}(z^{ij,i},z^{ij,j})+s^{ij}=0,\quad s^{ij}\ge0 \tag{16}$$

問題變成（代入指示函數 $I_{\Xi^i},I_{C^{ij}}$）：

$$\min_{\{\xi^i\},\{z^{ij,i},z^{ij,j},s^{ij}\}}\ \sum_{i}\big[J^i(\xi^i)+I_{\Xi^i}(\xi^i)\big]+\sum_{\{i,j\}}\big[\varphi(s^{ij})+I_{C^{ij}}\big]$$
$$\text{s.t.}\quad z^{ij,i}=\xi^i,\quad z^{ij,j}=\xi^j \tag{17}$$

其中

$$C^{ij}:=\{(z^{ij,i},z^{ij,j},s^{ij})\mid\psi^{ij}(z^{ij,i},z^{ij,j})+s^{ij}=0,\ s^{ij}>0\} \tag{18}$$

$I_{\Xi^i}(\xi^i)=0$ 若 $\xi^i\in\Xi^i$，否則 $+\infty$（$I_{C^{ij}}$ 同理）。

**這步的全部意義**：耦合 $\psi^{ij}$ 現在只碰**分身** $z$，不碰真身 $\xi$。真身之間的唯一聯繫變成 consensus $z=\xi$ —— 一個**線性**約束，正是 ADMM 兩塊形式 $\min f(x)+g(z)$ s.t. $x=z$。耦合被「外包」給 edge，node 之間徹底斷開。

**關於 (17) 的常見誤解（重要）**：$z=\xi$ 是**最終解**的性質，**不是迭代中途的性質**。下面 4.3 會看到 ADMM 把它鬆弛成增廣拉格朗日的罰項，所以**中途 $z\ne\xi$ 是允許且必要的**。「強迫相等會讓迭代無效」是把「最終解條件」誤當「每步條件」—— ADMM 從不在迭代中執行 $z=\xi$。

### 4.3 增廣拉格朗日推導（論文跳過的洞）

論文從 (17)/(18) 直接跳到 (19)–(21)，中間用一句「standard ADMM form, can be directly applied」帶過，把推導丟給 [32] Boyd Ch.3。但 Boyd 是通用 $x=z$，沒有 node–edge 那層「一個 $\xi^i$ 對多個 $z^{ij,i}$」的結構。以下補完整推導。

**Step 0：攤成標準兩塊形式。** 對應 $\min f(x)+g(z)$ s.t. $x-z=0$：

- **node 塊** $x=\{\xi^i\}_{i\in\mathcal{V}}$，$f(x)=\sum_i[J^i+I_{\Xi^i}]$
- **edge 塊** $z=\{z^{ij,i},z^{ij,j},s^{ij}\}_{\{i,j\}\in\mathcal{E}}$，$g(z)=\sum_{\{i,j\}}[\varphi+I_{C^{ij}}]$
- 每條邊貢獻**兩條**約束（i 端、j 端），因為一條邊牽兩個 node

目標函數在兩塊之間**完全沒有交叉項**，所有耦合都在線性約束 $\xi=z$ 裡 —— 這是 ADMM 兩塊交替能各自解耦的根本條件。

**Step 1：寫（unscaled）增廣拉格朗日。** 對每條約束配對偶：$y^{ij,i}$ 配 $\xi^i-z^{ij,i}=0$，$y^{ij,j}$ 配 $\xi^j-z^{ij,j}=0$。$L_\rho$ = 原目標 + 線性對偶項 + 二次罰項，每條邊兩端各一份 $y^\top(x-z)+\frac{\rho}{2}\|x-z\|^2$：

$$L_\rho=\sum_{i\in\mathcal{V}}\big[J^i+I_{\Xi^i}\big]+\sum_{\{i,j\}\in\mathcal{E}}\big[\varphi+I_{C^{ij}}\big]$$
$$+\sum_{\{i,j\}\in\mathcal{E}}\Big[(y^{ij,i})^\top(\xi^i-z^{ij,i})+\tfrac{\rho}{2}\|\xi^i-z^{ij,i}\|^2+(y^{ij,j})^\top(\xi^j-z^{ij,j})+\tfrac{\rho}{2}\|\xi^j-z^{ij,j}\|^2\Big]$$

> **約束從 hard 變 soft 的精確時刻**：consensus 約束 $\xi=z$ 從可行集邊界被搬進目標函數，變成「可違反、但要付代價」的罰項。中途 $\xi\ne z$ 從此被允許。

**Step 2：scaled 配方。** 令 scaled dual $\lambda:=y/\rho$、殘差 $r:=\xi^i-z^{ij,i}$，對「線性 + 二次」完全平方：

$$y^\top r+\frac{\rho}{2}\|r\|^2=\frac{\rho}{2}\Big\|r+\frac{y}{\rho}\Big\|^2-\frac{\rho}{2}\Big\|\frac{y}{\rho}\Big\|^2=\frac{\rho}{2}\|r+\lambda\|^2-\underbrace{\frac{\rho}{2}\|\lambda\|^2}_{\text{對最小化變數是常數，丟}}$$

代回，$L_\rho$ 變 scaled form：

$$L_\rho=\sum_i[J^i+I_{\Xi^i}]+\sum_{\{i,j\}}[\varphi+I_{C^{ij}}]+\frac{\rho}{2}\sum_{\{i,j\}}\Big[\|\xi^i-z^{ij,i}+\lambda^{ij,i}\|^2+\|\xi^j-z^{ij,j}+\lambda^{ij,j}\|^2\Big]+\text{const}$$

你的 $y^\top(x-z)$ 沒消失，被完全平方併進 $\frac{\rho}{2}\|x-z+\lambda\|^2$。論文用的就是這個 scaled 形式（$\lambda$ 被吸進二次項是 scaled 的標誌）。

**Step 3：Node update（固定 $z_p,\lambda_p$，對 $\{\xi^i\}$ 最小化）。** $\xi^i$ 出現在「每條與 $i$ 相連的邊」的 i 端罰項裡 —— 掃過所有鄰居 $j\in\mathcal{N}(i)$，邊 $\{i,j\}$ 上屬於 $i$ 的副本是 $z^{ij,i}$：

$$\boxed{\ \xi^i_{p+1}=\arg\min_{\xi^i\in\Xi^i}\ J^i(\xi^i)+\frac{\rho}{2}\sum_{j\in\mathcal{N}(i)}\|\xi^i-z^{ij,i}_p+\lambda^{ij,i}_p\|^2\ } \tag{19}$$

**完全對上論文 (19)。** 那個 $\sum_{j\in\mathcal{N}(i)}$ 是 node–edge splitting 的指紋 —— 來自「$\xi^i$ 在每條相連邊各有一個副本」。$z_p,\lambda_p$ 是常數，故各 $\xi^i$ 解耦、$n_\mathcal{V}$ 個 QP 可並行。

**化簡（實作有用）**：令 $c^{ij}_p:=z^{ij,i}_p-\lambda^{ij,i}_p$、$\bar c^i_p:=\frac{1}{|\mathcal{N}(i)|}\sum_{j\in\mathcal{N}(i)}c^{ij}_p$，則

$$\sum_{j\in\mathcal{N}(i)}\|\xi^i-c^{ij}_p\|^2=|\mathcal{N}(i)|\,\|\xi^i-\bar c^i_p\|^2+\text{const}$$

故 (19) 等價於把 $\xi^i$ 拉向鄰居目標的**平均** $\bar c^i_p$，權重 $\rho|\mathcal{N}(i)|$ → QP 的 Hessian 對角加 $\rho|\mathcal{N}(i)|I$、線性項加 $-\rho|\mathcal{N}(i)|\bar c^i_p$。

**Step 4：Edge update（固定 $\xi_{p+1},\lambda_p$，對 $\{z,s\}$ 最小化）。** 用 $\|\xi^i-z+\lambda\|^2=\|z-\xi^i-\lambda\|^2$ 翻符號：

$$\boxed{\begin{pmatrix}z^{ij,i}_{p+1}\\ z^{ij,j}_{p+1}\\ s^{ij}_{p+1}\end{pmatrix}=\arg\min_{(z^{ij,i},z^{ij,j},s^{ij})\in C^{ij}}\ \varphi(s^{ij})+\frac{\rho}{2}\|z^{ij,i}-\xi^i_{p+1}-\lambda^{ij,i}_p\|^2+\frac{\rho}{2}\|z^{ij,j}-\xi^j_{p+1}-\lambda^{ij,j}_p\|^2} \tag{20}$$

**完全對上論文 (20)。** inter-agent CBF 耦合 $\psi^{ij}$ 只活在 $C^{ij}$ 裡，只需 $i,j$ 兩端訊息。「分身為滿足 CBF 被推離真身」就在這步發生。$n_\mathcal{E}$ 個 QP 並行。

**Step 5：Dual update。** scaled 更新（$\lambda^+=\lambda+(x-z)$，無 $\rho$ 係數）：

$$\boxed{\ \lambda^{ij,i}_{p+1}=\lambda^{ij,i}_p+(\xi^i_{p+1}-z^{ij,i}_{p+1}),\qquad \lambda^{ij,j}_{p+1}=\lambda^{ij,j}_p+(\xi^j_{p+1}-z^{ij,j}_{p+1})\ } \tag{21}$$

**完全對上論文 (21)。** $\lambda$ 是殘差 $r=\xi-z$ 的累加，扮演積分回授：殘差不為零時 $\lambda$ 持續累積，透過 (19)(20) 偏移目標點把兩邊拉一致，收斂時 $r\to0$ → $\xi^i=z^{ij,i}$ → (17) 滿足。

### 4.4 三步的物理／實際意義

| 步驟 | 動的變數 | 固定 | 物理意義 | 實際意義 |
|---|---|---|---|---|
| Node (19) | 真身 $\xi$ | $z,\lambda$ | 在共識約束下走向自己目標 | 各 agent 並行解局部 QP |
| Edge (20) | 分身 $z$, $s$ | $\xi,\lambda$ | 兩兩協商，把路線挪開以避撞 | CBF 耦合的並行小 QP |
| Dual (21) | 對偶 $\lambda$ | $\xi,z$ | 記下分歧、下一輪施壓 | 殘差積分，逼 consensus 歸零 |

**一輪迭代的協商故事**：(1) 各機器人在「上輪談好的安全共識」下規劃走向目標；(2) 每對相鄰機器人檢查彼此路線會不會撞，撞則把共識路線挪開；(3) 測量「各自想走」與「協商要求」的分歧，累加進帳本 $\lambda$，下輪用它逼雙方靠攏。重複 → 分歧變小 → 真身分身趨於一致 → 收斂。

### 4.5 通訊協定與計算負載

**通訊**：每輪迭代後，agent $i$ 與每個鄰居 $j$ 交換 (a) 更新後真身 $\xi^i_{p+1}$，(b) 解完 edge 後的分身 $z^{ij,i}_{p+1},z^{ij,j}_{p+1}$。**全部只在節點與邊上局部交換，無全局通訊。**

**計算負載**：每輪 $n_\mathcal{V}$ 個 node 問題 + $n_\mathcal{E}$ 個 edge 問題，共 $n_\mathcal{V}+n_\mathcal{E}$ 個**互相獨立、可並行**的子問題。對 complete graph 負載對稱分散。

### 4.6 初始化（$z_0$）

ADMM 是迴圈，進迴圈前要備好 $z_0,\lambda_0,\rho$。$\lambda_0$ 通常設 0，$\rho$ 固定。$z_0$ 的填法：各 agent 解一次**無耦合** MPC $\hat\xi^i=\arg\min_{\xi^i\in\Xi^i}J^i(\xi^i)$（含局部動態 + obstacle CBF，**不含** inter-agent CBF），令 $z^{ij,i}_0=\hat\xi^i$。

**因果鏈**：(1) 各自解無耦合 MPC → $\hat\xi^i$（可能會撞）；(2) 填 $z_0$、$\lambda_0=0$ → 真身≈分身、殘差≈0；(3) 第一次 edge update：edge 發現分身違反安全 → 把分身推開 → 殘差「跳起來」；(4) 對偶 $\lambda$ 累積 → 後續把真身拉向被推開的分身 → 殘差單調下降 → 收斂。

**注意**：收斂與初值無關（凸情形），$z_0$ 只影響收斂速度、不影響終點。實務上穩態週期用 warm-start（上週期 $z,\lambda$ 平移一格），只有第一週期才用無耦合 MPC 當 $z_0$。

## Part 5：successive linearization 到 QP

### 5.1 問題：為什麼 (19)(20) 不能直接解

$\Xi^i$ 和 $C^{ij}$ 裡有兩種非線性：(a) 動態 (1) $x_{k+1}=f^i(x_k,u_k)$（kinematic car 的 $\cos\theta,\sin\theta$）；(b) CBF 約束 $\Delta h\ge-\alpha(h)$（$h$ 含 $\|\cdot\|$，非凸）。有這兩種非線性，(19)(20) 都不是 QP。

**successive linearization 的任務**：每個控制週期，把這兩種非線性在「當前操作點」做一階泰勒展開，凍結成線性，於是子問題變 QP。「successive」= 每週期重新線性化（用上週期解當展開點），是 RTI / SQP 家族。

### 5.2 Step A：線性化動態

設操作點為參考軌跡 $\{\bar x_k,\bar u_k\}$。對 $f^i$ 一階泰勒：

$$x_{k+1}\approx f^i(\bar x_k,\bar u_k)+A_k(x_k-\bar x_k)+B_k(u_k-\bar u_k),\quad A_k:=\frac{\partial f^i}{\partial x}\Big|_{\bar x_k,\bar u_k},\ B_k:=\frac{\partial f^i}{\partial u}\Big|_{\bar x_k,\bar u_k}$$

整理成 affine 線性動態：

$$x_{k+1}=A_kx_k+B_ku_k+c_k,\qquad c_k:=f^i(\bar x_k,\bar u_k)-A_k\bar x_k-B_k\bar u_k$$

$A_k,B_k,c_k$ 是凍結常數，**這是線性等式約束，QP 可吃**。

### 5.3 Step B：線性化 CBF 約束

CBF 條件 $h(x_{k+1})-h(x_k)\ge-\alpha(h(x_k))$，$h$ 非線性，在參考點 $\bar x$ 線性化：

$$h(x_k)\approx h(\bar x_k)+\nabla h(\bar x_k)^\top(x_k-\bar x_k)$$

代入，$\alpha$ 取線性後，整條約束變 $x,u$ 的仿射不等式 → QP 可吃。

### 5.4 Step C：組裝 QP

線性化完，(19) node update 變：

$$\min_{\xi^i}\ \tfrac12\xi^{i\top}H\xi^i+f^\top\xi^i\quad\text{s.t.}\quad A_{eq}\xi^i=b_{eq}\ (\text{線性化動態}),\quad A_{ineq}\xi^i\le b_{ineq}\ (\text{線性化 obstacle CBF})$$

- $H$：cost 的 $Q,R,P$ + 共識罰貢獻 $\rho|\mathcal{N}(i)|I$
- $f$：cost 線性項 + 共識罰 $-\rho|\mathcal{N}(i)|\bar c^i_p$
- 等式 = 線性化動態，不等式 = 線性化局部 obstacle CBF

(20) edge update 同理：cost 是 $\varphi(s)$ + 兩個 proximal 罰，約束是線性化 inter-agent CBF + slack。論文用 OSQP 解（max 200 iter）。

### 5.5 高層時間結構與雙重近似

論文把 successive-linearized ADMM-QP 放 **10 Hz** 高層，每週期：(1) 取當前狀態 + 上週期解當參考點；(2) 線性化動態與 CBF；(3) 跑 ADMM 三步，**最多 15 次迭代**（不收斂到底）；(4) 取第一步控制送下層。mid-level NMPC 50 Hz、low-level WBC 500 Hz。

**雙重近似**：(a) 線性化誤差（泰勒一階）；(b) ADMM 沒跑到收斂（殘差未歸零）。兩者靠 receding horizon（每週期重解）+ $d_{th}$ 餘裕吸收。這個「不精確但即時」的取捨是即時控制的本質。

## Part 6：收斂性深入

### 6.1 三個「收斂」層次

| 層次 | 保證強度 | 條件 |
|---|---|---|
| 凸 ADMM | 全局最優，與初值無關 | 整個問題凸 |
| 非凸 ADMM [33] | KKT 點（局部最優/駐點） | $\rho$ 夠大 + KŁ 性質等 |
| 實務（有限迭代） | 近似 KKT，無嚴格保證 | successive linearization + 15–20 輪 |

### 6.2 層次一：凸 ADMM 為什麼收斂

對凸問題 $\min f(x)+g(z)$ s.t. $x=z$，收斂靠兩量單調下降：

- **primal residual** $r_p=x_p-z_p$（約束違反量）
- **dual residual** $s_p=\rho(z_p-z_{p-1})$（分身變動量）

核心定理（Boyd [32]）保證 $r_p\to0$、$s_p\to0$、$f(x_p)+g(z_p)\to p^\star$。

**直覺**：ADMM 在找 $L_\rho$ 的鞍點。凸情形 $L_\rho$ 鞍點存在且唯一對應全局最優。可證 Lyapunov 函數 $\|z_p-z^\star\|^2+\|\lambda_p-\lambda^\star\|^2$（到最優點距離）單調遞減 + 有下界 → 必收斂。**對偶積分器把殘差逼到零，Lyapunov 距離單調下降保證到得了鞍點。** 此收斂與初值無關。

### 6.3 層次二：你的問題是非凸的 — 非凸性從哪來

**凸的部分**：cost $J^i$（正定二次）✓；動態（$A_d,B_d$ 線性）→ 仿射等式 ✓；牆 CBF（仿射）✓。

**非凸的部分（唯一來源）**：CBF 約束 $h^{ij}=\|p^i-p^j\|^2-d^2\ge0$。為什麼非凸？安全集是「排除一個圓盤」的區域 —— 圓盤外兩點連線可能穿過圓盤，故非凸。

**所以**：凸 cost + 凸動態 + 非凸 CBF 約束 → 整體非凸（只要一個非凸約束，可行集就非凸）。這是論文說 CBF "obscure the underlying separable structure" 的數學含義 —— 不只耦合，還破壞凸性。

### 6.4 層次三：非凸 ADMM 在什麼假設下收斂 [33]

論文引 [33] Wang-Yin-Zeng (2019)。主要假設（簡化）：

1. 目標函數有下界（coercive）
2. 某些區塊的 Lipschitz 可微性
3. **penalty $\rho$ 夠大**（超過與 Lipschitz 常數相關的門檻）
4. augmented Lagrangian 滿足 KŁ（Kurdyka-Łojasiewicz）性質

在這些假設下 [33] 證明：$L_\rho$ 沿迭代單調下降且有下界，序列 $(x_p,z_p,\lambda_p)$ 收斂到 **KKT 點**。

**誠實版意義**：(a) 拿不到「全局最優」保證（問題非凸）；(b) 能拿到「收斂到 KKT 點（局部最優/駐點）」，**前提是 $\rho$ 夠大**；(c) **$\rho$ 在非凸情形比凸更關鍵** —— 凸情形 $\rho$ 只影響速度，非凸情形 $\rho$ 太小可能根本不收斂。論文 $\rho=20$ 不只調速度，是要跨過收斂門檻。

> 調 $\rho$ 提示：殘差壓不下來時加大 $\rho$，不只「更快」，而是「可能從不收斂變收斂」。但 $\rho$ 過大會讓子問題病態、數值不穩，有甜蜜區間要實驗找。

### 6.5 層次四：successive linearization 救回凸性

雖然原問題非凸，但**每個控制週期內的子問題是凸的**：把非凸 CBF 在參考點線性化 → 仿射不等式 → 凸 → node QP 和 edge QP 都是凸 QP。

兩個時間尺度：

- **單週期內**：凸 QP，ADMM 享有層次一的凸收斂保證
- **跨週期**：successive linearization 是非凸外層迭代（像 SQP），逐週期逼近原非凸問題的 KKT 點

**標準套路**：外層（RTI/SQP）處理非凸，內層（每週期 ADMM）解凸子問題。內層有乾淨凸收斂，外層收斂靠 SQP-type 理論（參考點夠接近真解時線性化誤差小，逐週期改善）。

### 6.6 層次五：有限迭代（15–20 輪）的真相

理論收斂是 $p\to\infty$。只跑 15–20 輪 → 拿到**近似 KKT 點**。誠實說，有限迭代下**沒有**嚴格安全保證，只有：primal residual 被壓到有限值（非零）→ 真身軌跡近似（非精確）滿足 consensus → 近似滿足 inter-agent CBF。

**工程真相**：系統安全不是靠「ADMM 收斂定理」（那是漸近結果），而是靠「receding horizon 每週期重解 + 安全餘裕 + 殘差夠小」的工程組合。理論告訴你「會收斂、$\rho$ 要夠大、子問題凸」，實際安全要用數據驗證（log 殘差 + 真身 CBF 違反量）。

## 附錄 A：鞍點與積分回授的直覺

### A.1 鞍點是什麼

鞍點 = 微積分裡「一個方向最低、另一個方向最高」的臨界點。經典例子 $z=x^2-y^2$ 在原點：沿 $x$ 是開口向上拋物線（最低），沿 $y$ 是開口向下拋物線（最高）。二階判別 $D=f_{xx}f_{yy}-(f_{xy})^2=(2)(-2)-0=-4<0$ → 鞍點（兩方向曲率異號）。

對 $L_\rho(\xi,z,\lambda)$：對原始變數 $(\xi,z)$ 是谷底（min），對對偶 $\lambda$ 是山頂（max）。ADMM 在找這個鞍點。

### A.2 為什麼最優解在鞍點

對偶項 $\lambda^\top(\xi-z)$ 是「違反約束的價格」。$\lambda$ 想最大化 $L_\rho$ = 調整價格讓「違反約束」越來越不划算；原始變數想最小化 = 在價格下優化目標。這場 min-max 博弈的均衡（鞍點）恰好落在「約束滿足 $\xi=z$ + 目標最優」。

### A.3 第三步為什麼是積分

$L_\rho$ 對 $\lambda$ 的梯度 = 殘差：$\partial L_\rho/\partial\lambda=\xi-z=r$。dual update 是沿梯度上升一步：$\lambda_{p+1}=\lambda_p+r_{p+1}$。展開：

$$\lambda_p=\lambda_0+\sum_{k=1}^p r_k$$

$\lambda$ 是殘差的**累加（離散積分）**，扮演積分控制器。只要殘差未歸零就持續累積、加大修正力道，逼穩態誤差到零（對比純比例會留穩態誤差）。正是 $\lambda$ 這個積分項保證收斂時 $\xi=z$ 精確成立。
